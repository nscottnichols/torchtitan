## Known Issues

### torch.compile + `sdpa_kernel(set_priority=True)` on Polaris (FIXED)

Initial runs crashed with `RuntimeError('Invalid backend')` during `torch.compile`
tracing of `F.scaled_dot_product_attention` inside a `sdpa_kernel(..., set_priority=True)`
context manager.

**Root cause:** `torch._dynamo` bug in PyTorch 2.11 — `SDPAKernelVariable.enter()`
in `ctx_manager.py` creates FX graph nodes that pass proxy objects to `int()` when
`set_priority=True`, producing invalid backend IDs for `_set_sdp_priority_order()`.

**Fix:** `EzpzScaledDotProductAttention` subclass overrides `forward()` to use
`sdpa_kernel(self.sdpa_backends)` without `set_priority=True`. Device-aware
`_default_inner_attention()` selects the right subclass (XPU vs CUDA).
