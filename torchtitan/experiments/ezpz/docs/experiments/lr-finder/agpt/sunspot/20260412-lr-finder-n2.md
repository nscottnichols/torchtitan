## Method

Exponential LR sweep following [Smith 2015](https://arxiv.org/abs/1506.01186).
5 warmup steps at `init_lr=1e-6` to let the model settle, then 95 sweep steps
with `mult = (max_lr / init_lr)^(1/95)` = 1.157.
Loss is tracked with EMA smoothing (beta=0.98, bias-corrected).

Blow-up point detected by `find_optimal_lr()` (derivative analysis with
`smooth_frac=0.05`). **Suggested LR = blow-up / 10.**

Weight init uses `std = sqrt(2/(5*d))` following
[arXiv:2312.16903](https://arxiv.org/abs/2312.16903), ported from
Megatron-DeepSpeed. This gives smaller initial weights for larger models
(2B: std=0.014, 20B: std=0.0088), improving stability.

## Key Findings

### 1. Optimizer sensitivity ordering

```
AdamW (most tolerant) > Muon > SophiaG (most sensitive)
```

Consistent across all three machines.

### 2. Effect of dim-aware weight init

The `sqrt(2/(5*d))` init (vs fixed `std=0.02`) most significantly affects Muon:

| Model | Opt | Old LR (std=0.02) | New LR (sqrt(2/5d)) | Change |
|-------|-----|-------|--------|--------|
| 2B | Muon | 7.5e-4 | 2.4e-3 | 3x higher |
| 20B | Muon | 1.7e-5 | 1.7e-4 | 10x higher |
| 2B | AdamW | 1.9e-3 | 1.3e-3 | ~same |
| 20B | AdamW | 3.4e-4 | 4.0e-4 | ~same |
| 2B | SophiaG | 3.0e-4 | 3.1e-4 | same |
| 20B | SophiaG | 1.5e-5 | 1.8e-5 | same |

Muon's orthogonal momentum is sensitive to initial weight scale — smaller
init weights mean smaller gradients, so Muon can tolerate higher LRs.
AdamW and SophiaG are relatively unaffected.

### 3. Recommended Learning Rates

| Model | AdamW   | Muon    | SophiaG |
|-------|---------|---------|---------|
| 2B    | 1.3e-3  | 2.4e-3  | 3.1e-4  |
| 20B   | 4.0e-4  | 1.7e-4  | 1.8e-5  |
